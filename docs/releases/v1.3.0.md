# v1.3.0 — Biometric Passkeys, Stealth Mode & Inactivity Lock

### 📖 Description
Major privacy and security milestone introducing WebAuthn biometric unlock, instant privacy pixelation, real-time spending velocity analysis, and group debt settlement.

### ✨ What's Added
- **WebAuthn Biometric Passkeys**: Instant unlock using Face ID, Touch ID, and Windows Hello fingerprint sensors.
- **Privacy Stealth Mode**: One-tap pixelated blur mask across all financial balances for safe viewing in public.
- **Spending Velocity Gauge**: Real-time spending speed tracking (Weekly / Monthly pace vs prior benchmarks).
- **Trip & Group Debt Solver**: Smart group split manager with debt-minimization algorithm to settle shared expenses.
- **2–3 Minute Inactivity Auto-Lock**: Automatically secures the vault when unattended.
- **Dashboard Preferences Modal**: Interactive toggles to customize widgets, velocity gauges, and charts.
- **Environment Username Support**: Configurable vault owner display name via `NEXT_PUBLIC_USER_NAME`.
- **High-Resolution PWA Icons**: Crisp app icons for Android and iOS home screen installation.

### 🗑️ What's Removed / Deprecated from v1.2.0
- **Removed aggressive auto-lock on page refresh**: Replaced with a smooth 2–3 min inactivity timeout.
- **Removed redundant currency badges**: Cleaned up repetitive INR tags across cards for higher visual clarity.
- **Removed email requirement**: Simplified profile management to a sovereign display name.
- **Removed redundant settings buttons**: Streamlined profile header card into clean action shortcuts.
