# v1.4.0 — Sovereign Backup & Restore, Passbook History & 70% Performance Boost

### 📖 Description
Disaster recovery and performance overhaul release featuring complete offline JSON backups, interactive restore with safe merge and replace modes, historical passbook exports with smart emoji transliteration, and a massive ~70% reduction in bundle size.

### ✨ What's Added
- **Full Vault Data Backup (`GET /api/backup`)**: One-click download of an offline JSON snapshot containing all transactions, friends, categories, and dues.
- **Interactive Restore Modal (`POST /api/restore`)**: Drag-and-drop backup inspection, count preview, safe non-destructive merge, and clean replace with confirmation safeguard.
- **"All Time" Friend Ledger Scope**: Export 100% of historical transactions, splits, and deposits for any friend without date truncation.
- **Smart Emoji Transliterator for PDFs**: Converts emojis (🍕, 🚕, ☕) into clean text tags in bank-grade PDFs while preserving native full-color UTF-8 emojis in Excel.
- **1-Line Friend Actions Toolbar**: Unified mobile action row: `Download`, `Deposit`, `Spend`, `Detail`, `Settle Up`.
- **Next.js Dynamic Code-Splitting**: Code-split heavy export engines (`xlsx`, `jspdf`), cutting First Load JS by ~70% (e.g. `/ledger` dropped from 348 kB to 98.6 kB).
- **Starfield Canvas Overhaul**: Removed duplicate canvas instances, eliminated costly software `shadowBlur`, and added automatic pause on hidden tabs.
- **MongoDB Text & Compound Indexes**: Indexed text search on transaction notes and compound queries on friend dues.
- **Production Hardening**: Console log stripping and HTTP security headers (`nosniff`, `DENY`, `strict-origin`).

### 🗑️ What's Removed / Deprecated from v1.3.0
- **Removed multi-line wrapped button layout**: Reorganized all friend card actions into 1 clean mobile row.
- **Removed duplicate 60 FPS canvas instances**: Consolidated into a single global background canvas.
- **Removed empty whitespace gaps in PDFs**: Solved missing emoji glyphs via smart transliteration tags.
- **Removed uneven gradient text shading**: Replaced with uniform bright solid typography for "RupeePulse".
