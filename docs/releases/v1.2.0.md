# v1.2.0 — Executive Statements & High-Speed SWR Caching

### 📖 Description
Introduces audit-grade financial statement exports in Executive PDF and multi-sheet Excel formats, alongside zero-latency client-side SWR caching and vault security enhancements.

### ✨ What's Added
- **Executive PDF Export**: Auditable financial statements with formal header, currency formatting, and auto-tables.
- **Multi-Sheet Excel (.xlsx) Export**: Formatted spreadsheets with categorized tabs and totals.
- **Flexible Period Filters**: Export statements by Month, Week, Day, Year, or Custom Date ranges.
- **Direct Profile Export**: Export statement modal integrated directly into the Profile tab.
- **Client-Side SWR Cache (`lib/clientCache.ts`)**: In-memory and session cache providing instant 0ms tab navigation.
- **6-Digit PIN Vault**: Military-grade vault security upgrade with tactile keypad ergonomics.
- **Interactive 2x2 Statcards**: Dashboard layout revamp with real-time balance metrics.
- **Transaction Editor**: Inline editing modal to modify past entries without recreating them.

### 🗑️ What's Removed / Deprecated from v1.1.0
- **Removed 4-digit PIN**: Replaced with 6-digit PIN vault for stronger cryptographic protection.
- **Removed full page reload checks**: Replaced with smooth client-side SWR memory cache.
- **Removed isolated settled dues tables**: Consolidated into a unified continuous passbook history.
