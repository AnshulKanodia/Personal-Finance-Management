# v1.1.0 — Core Foundation & OLED Dark Architecture

### 📖 Description
Initial stable release of RupeePulse, establishing the sovereign single-user personal finance ecosystem architected specifically for INR currency with an OLED cosmic dark aesthetic.

### ✨ What's Added
- **Next.js 14 Progressive Web App (PWA)**: Mobile-first installation with offline caching and responsive touch layouts.
- **Tailwind OLED Dark Theme**: Ultra-dark `#060608` background with emerald accents, glass panels, and ambient glow.
- **MongoDB Connection Pooling**: Resilient connection management with DNS SRV fallback and warm connection reuse.
- **Core Mongoose Schemas**: Models for `Transaction`, `Category`, `Friend`, and `FriendDue`.
- **Backend REST API**: Full endpoints for transactions, categories, friends, split dues settlement, and PIN auth.
- **Interactive Dashboard**: High-level spending vs income tracking, cash balances, and recent transaction feeds.
- **Expense Tracker**: Real-time filtering by category, payment mode (UPI, Cash, Card, Net Banking), and month.
- **Khaata Friend Ledger**: Continuous ledger passbook with single net running balance and split adjustments.
- **60 FPS Cosmic Starfield**: Ambient HTML5 canvas background.
- **Polyglot Audit Engines**: Quantitative analysis tools in Python, Go, SQL, and Docker.

### 🗑️ What's Removed / Deprecated
- Initial release; replaced legacy multi-entry manual ledger sheets with a unified double-entry schema.
